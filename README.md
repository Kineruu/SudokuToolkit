# SudokuToolkit

A simple Python toolkit for working with a popular board game - "Sudoku".
This toolkit includes both generating and solving functions in invididual files.

## Features

1. Generate.py

User can pick the difficulty - the code will remove X or Y amount of numbers from each row:
    -> EASY - 1 or 2 numbers
    -> MEDIUM - 3 or 4 numbers
    -> HARD - 5 or 6 numbers
    -> EXPERT - 7 or 8 numbers

2. Solver.py

User has to manually enter the numbers to the board, row by row.
Use 0 or # to enter empty cells.
The program will print the solved board.
